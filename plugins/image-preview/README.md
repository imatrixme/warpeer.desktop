# Image Preview

The bundled reference Warpeer plugin. It recognizes explicit PNG and JPEG
resources under the terminal pointer and renders the complete hover surface in
PocketJS. The host grants only the exact local file or HTTPS target represented
by the active immutable hover context.

Rebuild the checked-in package deliberately with:

```sh
script/warpeer/build-image-preview-plugin
```

Normal Warpeer builds consume the checked-in `.warpeerplugin` and never fetch
PocketJS or run Bun.
