# Security Policy

Please do not report security vulnerabilities in public issues.

Report them privately through
[GitHub Security Advisories](https://github.com/imatrixme/warpeer.desktop/security/advisories/new).
Include the affected version, steps to reproduce, and the impact you observed.

Vulnerabilities that also affect upstream Warp should additionally be reported to Warp by
following the policy in the [Warp repository](https://github.com/warpdotdev/warp/security).
